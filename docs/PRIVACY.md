# 公开范围与脱敏

这个仓库是独立整理的公开文本源代码树，首次提交前完成检查，不包含此前本地工作目录的历史。

移除的现场信息包括：教师及学生真实 IP、实际组播地址、用户名和用户目录、主机名、网卡标识、MAC、机器/接口 GUID、设备序列号、课堂内容、抓包、图像、日志、崩溃转储、安装介质、厂商程序和本地快捷方式。版本、进程名、协议端口、字段布局与匿名样本统计作为技术复现信息保留。

文档使用 `203.0.113.10` 和 `192.0.2.20` 作为示例单播地址，`239.255.0.1` 作为示例组播地址。它们不能照抄用于实际课堂。`127.0.0.1` 是程序真实使用的本机输出地址。测试只使用人工构造的字节与本机 HTTP。

运行 `control status` 会在自己的终端显示本机服务路径和进程信息；程序不保存它们。命令行填写的现场地址可能留在使用者自己的 shell 历史中。分享终端输出、issue 或自制启动脚本前仍需检查内容。

`.gitignore` 排除常见配置、录制、诊断和构建产物。可以在提交前执行：

```powershell
python tools/check_public_tree.py
```

检查范围是 Git 可发布文件及暂存区文本；包含常见内网地址、绝对用户路径、GUID、MAC 和令牌模式。它不是通用秘密检测器，不扫描任意旧提交，也不能识别所有个人信息。发布时还应审阅文件清单、正文、提交作者/邮箱和整个将要发布的历史。

本仓库首个提交使用匿名贡献者身份，没有配置远端。公开上传应以此仓库或它的 Git archive 为范围，不要连同上级目录、旁边的实验草稿和本地数据一起上传。
