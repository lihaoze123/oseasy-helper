# Linux 学生端兼容实现与验证

本轮范围由用户确认：在线识别、视频和文件接收。实现基于所研究的 10.9.0.4820 协议，未声称完整替代所有原厂功能。

## 使用

```bash
uv run oseasy-helper student --teacher 10.115.4.137 --local 本机课堂IPv4
```

`student` 同时运行管理连接、文件节点、文件监听及本机 HTTP 视频输出，默认回复 MOCK 测试缩略图；视频由 mpv / VLC 解码和显示。`client` 保留为登录与收件入口，可通过 `--video` 开启视频；独立 `video` 入口保留。

Linux/Nix 用户可在外层项目使用：

```bash
nix develop .#helper -c uv run --project oseasy-helper oseasy-helper student --teacher 10.115.4.137 --local 本机课堂IPv4
```

教师端可能依赖原设备的计算机名、用户名或 MAC；可显式配置 `--name`、`--user`、`--mac`。程序不以 TCP 建立、收到管理命令或缩略图发送成功代替教师界面在线确认。

## 本轮行为

| 链路 | 实现 |
| --- | --- |
| 管理 TCP 9003 | 保留原登录字段布局；默认回复 64×64 JPEG 请求及收件目录查询；断线重新登录；60 秒无管理数据触发重连 |
| 视频 UDP 7778 | 加入指定网卡上的组播、重组 H.264、通过本机 HTTP 提供 MPEG-TS；管理重连不停止视频 |
| 文件节点 TCP 8555 | 心跳 6、就绪 7、接收任务 3；断线重试并丢弃旧连接的任务和报告 |
| 文件数据 | 默认监听 9100；任务可指定其他端口，仅绑定配置的本机网卡；接受教师及任务指定发送节点 |
| 文件结果 | 校验内容并落盘后 ACK；整次结束 ACK 成功后发节点报告 5 和重新就绪 7；不跨任务或节点连接复用完成结果 |
| 退出 | 停止并回收本程序的文件、视频线程及监听；不设置自启，不启停原厂服务 |

接收来源基于教师连接所提供的任务和源 IP，不构成密码学认证。同一端口只有一个当前任务；重复任务不替换原身份，冲突任务记录拒绝。不同端口可并行接收，监听上限 8，空闲动态端口可回收。未建立数据连接的任务 60 秒后过期，进行中的传输不受这个任务等待时间限制。

视频初次绑定失败时记录 `video_unavailable` 并继续管理与收件；接收线程异常记录 `video_error`。目录路径仍限定在用户选择的收件根目录下，传输内使用相对名字；不自动执行文件或按教师绝对路径写入。

## 自动测试

本地 Linux / Python 3.14.7 / psutil 7.2.2 和远端 Linux / Python 3.13.3 / psutil 7.2.2 均通过全部 45 项测试：

```bash
uv run --locked python -m unittest discover -s tests -q
```

新增真实 socket 测试覆盖：

- 登录后 JPEG 请求和目录请求的回复。
- 管理连接断开、静默超时后再次登录。
- 管理重连期间文件传输继续，内容和完成报告正确。
- 任务动态端口、任务指定的其他发送节点、无关来源拒绝。
- 重复及冲突任务、任务超时、旧节点连接报告丢弃、多端口报告保持独立。
- 端口绑定失败、空闲监听回收、视频启动失败后的管理继续运行。
- UDP 重组到 HTTP TS 输出、SIGINT 退出及监听释放。

自动视频测试使用结构性 NAL 数据，不用于证明实际像素解码。实际解码由下面的独立现场样本验证。
